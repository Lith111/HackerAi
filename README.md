## 📖 نظرة عامة

**Cyber Mentor** هي منصة ويب تعليمية متخصصة في الأمن السيبراني واختبار الاختراق. تدمج المنصة بين **التعلم النظري التبايني** (شرح الثغرة ← استغلالها ← شرح الحماية ← تطبيق الحماية) و**التطبيق العملي عبر محاكي طرفية وهمي** (Terminal)، مع وجود **مساعد ذكاء اصطناعي** يُقدّم تلميحات مؤقتة (10 ثوانٍ فقط) لتعزيز الفهم وتحدي المتعلم.

المنصة موجّهة لفئتين من المستخدمين: **المدراء** (لإدارة المحتوى والطلاب) و**الطلاب** (للتعلم والاختبار). تعتمد المنصة على نظام **تسلسل إجباري** يفرض على الطالب إنهاء كل درس (بأقسامه الأربعة) قبل الانتقال إلى الدرس الذي يليه، مع **مسارين تخصصيين**: مسار **الهجوم (Red Team)** ومسار **الدفاع (Blue Team)**.

## ✨ المميزات الأساسية

### 🧠 نظام تعلم تبايني (4 مراحل لكل درس)
ينقسم كل درس إلى أربعة أقسام إجبارية متسلسلة:
1. **شرح نظري للثغرة** – المفهوم، كيفية العمل، الأثر.
2. **مثال اختراق عملي** – كود ضعيف مع شرح طريقة استغلاله.
3. **شرح نظري لآلية الحماية** – مبادئ الدفاع وأفضل الممارسات.
4. **كود الحماية العملي** – الكود الآمن مع عرض الفرق بينه وبين الكود غير الآمن.

### 🖥️ محاكي طرفية وهمي (Virtual Terminal Lab)
- محاكاة لـ **Terminal** حقيقي داخل المتصفح (باستخدام `xterm.js`).
- الطالب يُدخل أوامر لاختراق أو حماية أنظمة افتراضية، ويتم تقييمها لحظياً مقابل قاعدة بيانات الأوامر الصحيحة.
- رسالة "command not found" تُحاكي التجربة الحقيقية عند الخطأ.

### 🤖 مساعد ذكاء اصطناعي مؤقت (10-Second AI Helper)
- عندما يخطئ الطالب في المختبر، يُعرض عليه **طلب المساعدة**.
- عند القبول، يُرسل سجل الجلسة كاملاً إلى نموذج ذكاء اصطناعي (OpenAI) لاقتراح الحل.
- **الحل يظهر لمدة 10 ثوانٍ فقط** ثم يختفي تلقائياً مع إعادة تعيين الجلسة، مما يجبر الطالب على تذكر ما فهمه وتطبيقه بنفسه.

### 💬 شات بوت تعليمي
- مساعد ذكي دائم للإجابة عن الأسئلة النظرية وشرح المفاهيم.
- مُدرَّب على عدم إعطاء إجابات مباشرة لأسئلة الاختبارات.

### 📊 لوحات متابعة وتقارير
- **لوحة الطالب**: شريط تقدم بصري، الدروس المتاحة والمكتملة، الوصول إلى المختبر.
- **لوحة المدير**: إحصائيات عامة، تتبع تقدم كل طالب، إدارة المحتوى والمستخدمين.

### 🔒 تسلسل إجباري ومساران تخصصيان
- لا يمكن فتح أي درس قبل إتمام الدرس السابق بأقسامه الأربعة كاملة.
- مساران منفصلان: **Red Teaming (اختراق)** و **Blue Teaming (حماية)**.

## 🏗️ التقنيات المستخدمة

### الواجهة الأمامية (Frontend)
- **React.js** (مع Vite)
- **Redux Toolkit** (لإدارة الحالة)
- **React Router DOM** (للتوجيه)
- **Tailwind CSS** (للتصميم العصري والمظهر الداكن)
- **xterm.js** (لمحاكاة الطرفية)

### الواجهة الخلفية (Backend)
- **Django 5.x** + **Django REST Framework (DRF)**
- **Django Channels** + **Daphne** (لاتصالات WebSocket)
- **Celery** + **RabbitMQ** (للمهام غير المتزامنة ومعالجة طلبات الذكاء الاصطناعي)
- **PostgreSQL** (قاعدة البيانات الأساسية)
- **Simple JWT** (للمصادقة)

### الذكاء الاصطناعي
- **OpenAI API** (GPT-4o/mini)

### النشر والإنتاج
- **Nginx** (وكيل عكسي)
- **Gunicorn** (خادم WSGI)
- **Daphne** (خادم ASGI للـ WebSockets)

## 🚀 التشغيل المحلي والتثبيت

### المتطلبات الأساسية
- **Python 3.12+** و **Node.js 20+**
- **PostgreSQL** (مُشغّل محلياً أو عبر Docker)
- **RabbitMQ** (أو يمكن استخدام قاعدة البيانات كبديل مؤقت في إعدادات Celery)

### إعداد الباك إند

```bash
# استنساخ المستودع
git clone https://github.com/your-org/cyber-mentor.git
cd cyber-mentor/backend

# إنشاء البيئة الافتراضية وتفعيلها
python -m venv venv
source venv/bin/activate  # أو venv\Scripts\activate على Windows

# تثبيت المكتبات
pip install -r requirements.txt

# إنشاء ملف .env من المثال (وتحريره بالمفاتيح المطلوبة)
cp .env.example .env

# تطبيق الهجرات وإنشاء قاعدة البيانات
python manage.py migrate

# تحميل بيانات أولية (سيناريوهات ودروس تجريبية اختياري)
python manage.py loaddata initial_data

# تشغيل خادم التطوير (يتطلب تشغيل Celery و Daphne في نوافذ منفصلة)
python manage.py runserver
```

في نوافذ طرفية منفصلة (أو باستخدام `supervisor`):
```bash
# تشغيل Celery worker
celery -A config worker --loglevel=info

# تشغيل خادم ASGI للـ WebSockets (يمكن الاكتفاء بـ runserver في التطوير)
daphne config.asgi:application
```

### إعداد الفرونت إند

```bash
cd ../frontend

# تثبيت الاعتماديات
npm install

# نسخ ملف البيئة وتعديل عنوان الباك إند
cp .env.example .env

# تشغيل خادم التطوير
npm run dev
```

ستكون المنصة متاحة على `http://localhost:5173` (الواجهة الأمامية) والـ API على `http://localhost:8000/api/`.

## 🧪 الاستخدام

### كمدير (Admin)
1. سجّل الدخول باستخدام حساب المدير.
2. من لوحة التحكم، أضف مستخدمين، أنشئ دروساً بأقسامها الأربعة.
3. أنشئ سيناريوهات للمختبر مع الأوامر الصحيحة والنماذج.
4. تابع تقدم الطلاب والإحصائيات.

### كطالب (Student)
1. سجّل واختر مسار التعلم (اختراق / حماية).
2. ابدأ الدرس الأول واتبع الأقسام الأربعة.
3. لا يمكنك الانتقال للدرس التالي قبل إنهاء الدرس الحالي.
4. بعد إنهاء الدروس، توجه إلى المختبر لاختبار مهاراتك في الطرفية الوهمية.
5. استخدم الشات بوت لأي استفسار نظري.

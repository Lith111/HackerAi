
# خطة تطوير واجهة المستخدم (Frontend Development Plan)
**التقنيات:** React JS, Redux Toolkit, Tailwind CSS, React Router DOM
**الهدف:** بناء واجهة عصرية، جذابة بصرياً، متجاوبة مع جميع الشاشات، وتوفر تجربة مستخدم سلسة.

---

## 1. الإعداد والبنية الأساسية للمشروع (Project Structure & Theme Setup)

قبل البدء، سيتم تنظيم المشروع على النحو التالي:

**أ. هيكل المجلدات (Folder Structure):**
```
src/
├── assets/             # الصور، الأيقونات، الخطوط
├── components/         # المكونات القابلة لإعادة الاستخدام (أزرار، بطاقات، Navbar, Footer)
├── pages/              # الصفحات الرئيسية (Home, Lessons, Lab, Dashboard...)
├── features/           # شرائح Redux Toolkit (authSlice, lessonSlice...)
├── layouts/            # الهياكل العامة للصفحات (MainLayout, DashboardLayout)
├── styles/             # إعدادات Tailwind الإضافية أو الأنماط العامة
└── App.jsx
```

**ب. إعداد نظام التصميم والألوان (Design System via Tailwind):**
لتلبية طلبك بـ "ألوان عصرية ومظهر شديد الجمال" سنخصص إعدادات `tailwind.config.js`:

- **الوضع المظلم (Dark Mode) سائد:** لأنه معيار الجمال الحديث في منصات التقنية والسيبراني.
- **لوحة الألوان الأساسية:** 
    - **الخلفية العميقة:** أزرق داكن جداً مائل للسواد (`slate-900`, `slate-950`).
    - **اللون التوكيدي الأساسي:** **سماوي كهربائي (Cyan-400)** لإيحاء التقنية والحداثة.
    - **اللون الثانوي:** بنفسجي فاتح (`violet-400`) لإضفاء لمسة جمالية جذابة.
    - **الألوان الوظيفية:** أخضر (`emerald-400`) للنجاح والأمان، وأحمر (`rose-500`) للأخطاء والاختراق.
- **خطوط عصرية (Fonts):** خط `Inter` أو `Poppins` للنصوص الأساسية، وخط `Fira Code` للمقاطع البرمجية والتيرمنال.
- **التأثيرات:** زوايا دائرية (`rounded-2xl`)، تأثير زجاجي (`backdrop-blur`)، وتدرجات لونية خفيفة جداً.

## 2. توصيف الصفحات (Pages Description)

### أ. صفحة الرئيسية (Home Page) - أهم صفحة
هذه الصفحة هي الانطباع الأول، ويجب أن تروي قصة المنصة كاملة. ستتكون من الأقسام التالية:

1.  **شريط التنقل العلوي (Navbar):**
    - شفاف جزئياً مع تأثير زجاجي (`backdrop-blur`).
    - شعار المنصة على اليسار.
    - روابط: الرئيسية، عن المنصة، فريق التطوير، اتصل بنا.
    - زران لامعان: "تسجيل الدخول" (بإطار سماوي) و"ابدأ الآن" (بخلفية سماوية متدرجة).

2.  **القسم البطولي (Hero Section):**
    - خلفية متحركة: شبكة رقمية أو شيفرة برمجية تتساقط بتأثير شفاف.
    - عنوان رئيسي ضخم (بالعربية): "أتقن فنون الأمن السيبراني... من الصفر للاحتراف".
    - عنوان فرعي: يشرح القيمة الفريدة للمنصة بأسلوب تسويقي مختصر.
    - دعوتان (CTA): "ابدأ مسار الاختراق" (بلون أحمر خافت) و"ابدأ مسار الحماية" (بلون أزرق).
    - رسم ثلاثي الأبعاد (Illustration) لترس أو درع سيبراني.

3.  **قسم "كيف تعمل المنصة؟" (How it Works):**
    - 4 بطاقات زجاجية مرتبة أفقياً، كل بطاقة تشرح خطوة من رحلة الطالب:
        - **البطاقة 1:** "تعلم" - درس نظري متكامل (أيقونة كتاب).
        - **البطاقة 2:** "طبق" - مختبر تيرمنال وهمي (أيقونة محطة طرفية).
        - **البطاقة 3:** "أخطئ" - الحصول على مساعدة ذكية ومؤقتة (أيقونة روبوت).
        - **البطاقة 4:** "اتقن" - إعادة المحاولة وإثبات المهارة (أيقونة شهادة).

4.  **قسم "المميزات الأساسية" (Core Features):**
    - شبكة من 3 أعمدة تحتوي على بطاقات مميزة:
        - "أسلوب التعلم التبايني": شرح 4 أقسام الدرس.
        - "الذكاء الاصطناعي المرشد": شات بوت ومساعد الـ 10 ثواني.
        - "مسارات تخصصية": شرح لمسار الهجوم ومسار الدفاع.

5.  **قسم "فريق التطوير" (The Team):**
    - عنوان: "خلف هذه المنصة".
    - بطاقات دائرية أو نصف دائرية للأعضاء، مع تأثير حركي عند المرور (`hover`).
    - صورة أو أفاتار، الاسم، الدور (مبرمج فرونت، محلل أنظمة...)، رابط GitHub أو LinkedIn.

6.  **قسم "الأسئلة الشائعة" (FAQ):**
    - تصميم أكورديون (Accordion) أنيق.
    - إجابات عن: هل المنصة مجانية؟ هل أحتاج خبرة سابقة؟ كيف أختار بين المسارين؟.

7.  **تذييل الصفحة (Footer):**
    - خلفية داكنة جداً.
    - شعار المنصة، روابط سريعة، أيقونات وسائل التواصل.
    - نموذج اشتراك في النشرة البريدية (إن وجد).

---

### ب. باقي صفحات المنصة

- **صفحة تسجيل الدخول / التسجيل (Auth Page):**
    - تصميم مقسم لنصفين: نصف فيه النموذج (بخلفية داكنة)، والنصف الآخر رسم توضيحي كبير.
    - تأثيرات حركية عند التبديل بين تسجيل الدخول وإنشاء الحساب.
    - حقول إدخال بتصميم بسيط بحدود متوهجة عند التركيز.

- **لوحة تحكم الطالب (Student Dashboard):**
    - شريط جانبي (Sidebar) قابل للطي.
    - ترحيب: "مرحباً، [الاسم]!".
    - بطاقة "مسارك الحالي" توضح المسار المختار وشريط التقدم العام.
    - قائمة الدروس مع أيقونات (مفتوح، مكتمل، مغلق) وتأثيرات قفل للدروس غير المتاحة.

- **صفحة الدرس (Lesson Page):**
    - **شريط تقدم داخلي** يوضح الأقسام الأربعة التي تمر بها.
    - عرض المحتوى في منتصف الشاشة بمساحة واسعة ومريحة للعين.
    - عرض الأكواد البرمجية داخل صندوق داكن مع ترقيم الأسطر وتلوين الصيغة.
    - عرض الفرق بين كود الاختراق وكود الحماية (Diff Viewer) بشكل بصري أنيق.
    - زر "التالي" لا يظهر إلا بعد الوصول لآخر الكتلة الرابعة.

- **مختبر التيرمنال (Lab Page):**
    - واجهة تحاكي 100% شكل شاشة طرفية لينكس أو ويندوز، داخل إطار متصفح.
    - شريط عنوان علوي وهمي بداخله اسم الجلسة.
    - خلفية سوداء عميقة مع نص أخضر أو أبيض بلون `Fira Code`.
    - عند تفعيل "المساعدة"، يظهر مربع حواري شفاف في منتصف الشاشة مع العد التنازلي `0:10` بوضوح، ثم يختفي.

## 3. إدارة الحالة والتفاعل مع البيانات (State Management)

- **`authSlice` (Redux Toolkit):** يدير جلسة المستخدم، الرمز (token)، وحالة تسجيل الدخول. يتحكم في ظهور محتوى معين (مثلاً: إظهار "لوحة التحكم" للمسجلين فقط).
- **`lessonSlice`:** يخزن الدروس التي تم تحميلها، تقدم كل درس، وقفل/فتح الدروس التالية. يضمن أن منطق التسلسل ينعكس مباشرة على الواجهة دون تأخير.
- **`labSlice`:** يدير حالة جلسة التيرمنال (متصل/غير متصل)، سجل الأوامر، حالة المساعدة (نشطة/مخفية).

## 4. خطة مرحلية للتنفيذ (Implementation Phases)

**المرحلة 1: الهيكل والتنقل**
- إنشاء المشروع بـ Vite + React.
- تثبيت المكتبات (Router, Redux, Tailwind).
- بناء `Layout` العام (Navbar + Footer).
- بناء `Router` والصفحات الفارغة.
- إعداد ثيم Tailwind المظلم والألوان.

**المرحلة 2: صفحة الهبوط (Home) - الأولوية القصوى**
- تطوير القسم البطولي بتأثيراته.
- بناء مكونات البطاقات القابلة لإعادة الاستخدام.
- تجميع كل أقسام الصفحة (كيف تعمل، المميزات، الفريق، الأسئلة الشائعة).
- التأكد من التجاوب الكامل (Responsive) على الجوال، الجهاز اللوحي، وسطح المكتب.

**المرحلة 3: المصادقة والدروس**
- بناء صفحة تسجيل الدخول والتسجيل.
- تطبيق منطق Redux لـ Auth.
- بناء صفحة لوحة التحكم وعرض الدروس.
- بناء صفحة الدرس بمكونات عرض الكود (Syntax Highlighter).

**المرحلة 4: المختبر والذكاء الاصطناعي**
- بناء واجهة التيرمنال باستخدام مكتبة `Xterm.js` وربطها بـ WebSocket وهمي.
- تطبيق منطق المساعدة المؤقتة مع المؤقت التنازلي.
- بناء واجهة الشات بوت (شريط جانبي أو نافذة منبثقة).

**المرحلة 5: التلميع النهائي**
- إضافة حركات وانتقالات سلسة (Framer Motion).
- تحسين الأداء (Lazy Loading).
- اختبار شامل على المتصفحات المختلفة.

---

### ملاحظة الخبير الجمالي:
للوصول إلى "مظهر شديد الجمال"، السر يكمن في **التفاصيل الدقيقة**:
1.  **الفراغ (Spacing):** استخدم `padding` و `margin` بشكل كبير لتعطي المحتوى مساحة للتنفس.
2.  **التدرجات (Gradients):** ضع تدرجاً خفيفاً جداً على الحدود الفاصلة بين الأقسام بدلاً من الخطوط الصلبة.
3.  **الحركة (Micro-interactions):** كل زر عند الضغط عليه، كل بطاقة عند المرور عليها، يجب أن تكون لها استجابة بصرية ناعمة. Tailwind تجعل هذا سهلاً جداً.
4.  **التناسق:** استخدم نفس عائلة الخطوط ونفس نصف قطر الزوايا في كل العناصر.
